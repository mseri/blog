How Rules Work

Binary is a way of writing numbers using only 0 and 1. Each position is worth twice the position to its right: 20 = 1, 21 = 2, 22 = 4, and so on. A 1 includes that value; a 0 does not. For example, 101 means 1 × 4 + 0 × 2 + 1 × 1 = 5.

A cellular-automaton rule has eight binary positions—one for each possible three-cell neighborhood. The display reads from 111 to 000: 111 uses the 27 (128) position, 110 uses 26 (64), and so on down to 000 using 20 (1). The bit below each neighborhood says what the middle cell becomes next: 1 is black and 0 is white. Adding the values selected by the 1s gives the rule number.

For example, Rule 30 is 00011110: 0 × 128 + 0 × 64 + 0 × 32 + 1 × 16 + 1 × 8 + 1 × 4 + 1 × 2 + 0 × 1 = 30. Therefore, its black next-generation neighborhoods are 100, 011, 010, and 001.

Cellular automata are a rich field of research, appealing to theorists and hobbyists while also having a broad range of applications. For more information, visit Wikipedia's Cellular automaton page.
